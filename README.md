# student_management-system

## Project Description
The Student Management System is a web-based application developed to manage student information efficiently. The system allows students to register accounts, login and view their personal profiles.
Administrators can manage student records

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Features
- Student self-registration
- Student login and logout
- Student dashboard
- Administrator login

## Installation
1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into the htdocs folder.
4. Open phpMyAdmin and create a database named student_management.
5. Import the student_management.sql file.
6. Open your browser and visit:
   http://localhost/student_management/login.php
   http://localhost/student_management/student_login.php
